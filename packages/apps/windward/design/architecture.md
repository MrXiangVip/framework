# 技术决策与开发约定

## 技术边界

Java 8，独立 APK/ClassLoader；原有框架拥有唯一可见 X11 窗口。
应用工作线程拥有隐藏 GLFW/OpenGL 上下文，FBO 绘制到 900×600，再读回 BufferedImage。
引用现有竞技场的实现模式；当前新应用不依赖竞技场应用或 Unity。
LWJGL 3.3.6 core/GLFW/OpenGL/Assimp 及 Linux x86_64 natives 来自仓库现有副本，独立打包。

## 职责与线程

- MainActivity：窗口、暂停、销毁。
- MountainView：UI 输入转换、命令队列、固定步长驱动、HUD、不可变完成帧。
- MountainWorld：无图形依赖的规则与角色控制器。
- MountainCamera：轨道镜头、地形/障碍采样避障。
- MountainInput：UI 线程键盘状态、大小写归一与重复过滤。
- MountainRenderer：GL 上下文、静态场景、读回和资源释放。
- MountainAssets/MountainArt：FBX 网格、LOD 与叶片拆分、纹理、静态几何缓存和角色绘制。
- TravellerRig：Fantasy 骨骼、权重、程序姿态、CPU 蒙皮与复用的顶点缓冲。

UI 通过队列传递命令，world/camera 只在工作线程访问。
渲染帧发布后不修改，避免 UI/GL 同时读写同一图像。
120Hz 固定模拟步长；每次最多累积 0.2s，暂停清空累计时间。
当前每帧分配 BufferedImage；测量若显示 GC 压力，再引入带租约的缓冲池。

## M1 几何规则

2m 网格三角形地形，碰撞高度使用与绘制一致的分片线性插值。
角色半径 0.36m；地面移动限制上坡 48°，逐轴滑动，活动区 ±48m。
树干、岩石、帐篷和符文石使用保守圆柱阻挡；未实现刚体、石头顶部站立、台阶攀登、天花板和复杂网格碰撞。
跳跃使用重力与地形落地；镜头从目标点向后每 0.1m 采样，遇地形/圆柱即收缩。
树冠、花草和远处山体是装饰；风塔内部尚不可探索、没有碰撞策略。
镜头遇到遮挡立即收近，离开遮挡后以指数缓动恢复距离（系数 5/s），避免突然拉远；恢复按模拟时间推进，暂停和完成界面冻结，重开清除缓动状态。旋转仍直接响应鼠标，不增加输入延迟。极端狭窄位置可能贴近角色；需人工试玩调节。

## AI 工作流适配

参考 ai/README.md 和工作室模板的一页策划、单功能实现、审查与证据交付思想。
不直接启用嵌套 slash commands/hooks，不修改模板引擎注册表，也不伪装成 Web/Unity 项目。
本阶段普通任务闭环：目标和保留行为 → 验收条件 → 实现 → 逻辑/图形/窗口检查 → 人工试玩。
不自动提交、推送或开启多代理。新能力先放应用内，真实复用需求出现后再抽公共模块。

## 素材

地形与风塔保持程序几何；树木、岩石、草花、帐篷、符文石来自 Meadow Forest。
旅行者使用 Anime Fantasy Pack 2 的完整男剑士；跳过未绑定骨骼的静态剑网格，当前没有武器战斗。
模型含 15 个使用中的网格、身体/衣服/头发材质和真实骨骼，无内嵌动作。
使用父子层级、bind transform、bone offset 和归一化权重 CPU 蒙皮。
站立降低原 T-pose 肩臂；行走按实际位移相位摆动四肢，跳跃使用基础屈膝姿态。
这是程序动作，尚无动作重定向、脚部 IK、披风/头发物理或原始 Unity shader 复现。
材质名称显式映射到本地 PNG，截断透明叶片；纹理 GPU 最长边 1024，开启 mipmap。
地形每个 10m 块按草地/山路两种贴图合批，保持原 2m 三角形、高度、法线与 UV；固定石轨和机关底座缓存为带保守包围球的静态绘制项，石块、充能圆盘和发光效果仍动态绘制。
场景以单档 LOD 编译 display list；角色复用蒙皮工作区和 native 顶点缓冲。
素材导入工具位于 tools/import-assets.py；res/world/asset-manifest.json 记录来源及双重校验值。
所有选用资源独立打包，运行不读取 external/ 或其他应用。素材使用遵循原包授权。

Meadow 原包存在 gzip CRC 错误，导入使用现有森林解包库并核对每项文件清单 SHA-256；
Fantasy 原包完整性检查通过，直接导入。此限制只影响重新导入，不影响独立 APK 运行。

## M2 路线状态

MountainJourney 保存顺序路标、符文石阅读与短时发现提示，由 MountainWorld 固定步长推进；暂停不推进，reset 清空。路线控制点同时定义山路中心和装饰路标，Frame 仅发布不可变 HUD 文本与交互状态。E 阅读仅在地面、符文石三米内且未暂停时有效；没有持久化存档或最终通关状态。

## M2 攀爬、滑翔和奖励

MountainTraversal 定义唯一可攀爬岩台的矩形范围、南侧入口与水平顶面，渲染、世界碰撞和镜头共用这些边界。普通石头仍使用原有圆柱阻挡，不能攀爬。MountainWorld 在固定步长中管理 climbing/gliding、100 点共享体力、落地和登顶；攀爬时 W/S 是垂直、A/D 是沿岩面横移，不随相机方向改变。地面 E 抓墙，E 或空格可脱离，登顶移入平台内形成稳定支撑。体力耗尽松手，地面恢复；没有伤害或死亡。

滑翔以空中空格切换，必须有 0.7m 离地高度和足够体力；下降速度限制 2.5m/s，方向输入仍相机相对，落地自动关闭。没有风场或空气动力模拟。Journey 保存登顶和单次遗物领取状态，R 清除。所有 UI 状态仍从 worker 发布的不可变 Frame 读取。翼面和遗物匣为原创几何原型，没有新增第三方资产。

## M3 基础战斗

MountainCombat 由 World 固定步长驱动，独立保存守卫状态（空闲、接近、蓄力、恢复、返回、击败）、双方生命、挥击计时、闪避和受击保护。玩家一次攻击持续 0.5 秒，0.12 秒时只检测一次：前方 2.4m 扇形、垂直差小于 1.3m 且障碍采样通畅。三次命中击败守卫；命中打断守卫蓄力。玩家挥击期间不能移动或跳跃，没有连击或空中攻击。

守卫在玩家进入 8m 范围、距原点不超过 10m 且同高度地面时接近；1.8m 内进入 0.7 秒锁定方向蓄力，挥击后恢复 0.85 秒。命中扣 25 生命，受击保护 0.65 秒；力竭冻结模拟和行动，R 重置整轮。敌人只进行轴向障碍避让，没有导航网格或角色间实体碰撞。

K 闪避消费 25 点共享体力，持续 0.32 秒、速度 10m/s，无敌窗口 0.04–0.26 秒，冷却 0.7 秒。方向来自相机相对输入，无输入则沿角色朝向；移动复用世界固体和边界判定。攻击/闪避与攀爬、滑翔互斥。Frame 发布战斗 HUD 快照；键盘和鼠标请求依旧经 worker 队列处理。练习剑从当前 hand_r 骨骼位置生成，守卫和预警为动态原创几何，不改变资产来源清单。

## M3 风塔机关与区域完成

MountainPuzzle 保存轨道石块位置、推石状态、圆盘充能和固定状态。E 靠近扶住石块，角色定位到南侧把手，W/S 沿世界 Z 轴推拉（不受镜头方向影响），速度 1.4m/s，轨道边界 [-29,-19]；E 松手。固定步长检查静态障碍，角色和石块同步移动。推石与跳跃、攻击、闪避互斥，不消耗体力。石块作为动态方形阻挡和顶面支撑，镜头也检测该方块；轨道和圆盘不作为实体障碍。东侧旧岩石移到远侧山坡，避免堵住推石入口。

圆盘中心为 (22,-27)，石块中心距它 Z 方向小于 0.55m 时累计一秒，移出即清除部分充能。满充能后固定当前位置，释放推石状态；不强行吸附到圆心，避免吸附导致角色夹入石块。塔旁石台 (18.5,-25) 地面两米内 E 激活，要求守卫已击败且圆盘已充能。无需隐藏遗物或按固定顺序经过全部路标；可以自由探索完成目标。

Journey 保存 complete、summaryOpen、completedAt。完成界面冻结模拟和行动，用时取本轮模拟时间（不含暂停/完成界面）；Enter 关闭界面继续探索，激活状态和完成用时保持，重复 E 不重复计时；R 清除一切本轮状态。没有磁盘存档。完成后塔顶风纹和光束为原创几何效果；塔身没有可进入内部，也未引入新第三方资源。
