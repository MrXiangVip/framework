# 风起山野 / Windward

沿用本仓库 Java 8 / Linux X11 / LWJGL / OpenGL 框架的原创明亮卡通山野冒险。
当前为半径约 1km 的球面世界实验，保留 M3 首个区域完整流程，已接入 Meadow Forest 场景与 Anime Fantasy Pack 2 角色。

## 构建与启动

仓库根目录：

```bash
bash packages/apps/build.sh windward
bash build.sh
```

在 Launcher 中点击“风起山野”（可能在后续页）。产物：
`out/system/app/windward/windward.apk`。Launcher 按 Manifest 自动发现，不需要修改桌面。
总入口会构建全部应用；本游戏单独构建、运行不依赖竞技场应用。
运行环境：Java 8+、Linux x86_64、X11、OpenGL 2.1 与 framebuffer object 支持。
唯一可见窗口由框架创建，隐藏 GL 上下文负责离屏渲染，无需 Unity 或下载素材。

## 当前内容与操作

- 主线：营地出发 → 击败守卫 → 东侧推石压盘 → 塔旁石台激活风塔 → 完成界面。
- 石块附近 E 扶住，W/S 沿轨道推拉，压住北端圆盘后松开方向键等待一秒；充能后石块固定。
- 完成后显示旅程用时与可选遗物收集，Enter 继续自由探索，R 重置整轮。
- 山路上的山谷守卫：J / 鼠标左键近战攻击，K 闪避；闪避沿当前移动输入方向，无方向输入时向角色前方。
- 守卫挥击前出现橙红色扇形预警；三次命中可击败，玩家生命耗尽后按 R 重开。
- 西侧浅色岩面：E 抓墙/松手，W/S 上下、A/D 横移；登顶后可站立和起跳。
- 空中距地面足够高时按空格展开滑翔翼，再按收起；方向键控制，落地自动收起。
- 闪避、攀爬和滑翔共用体力，耗尽会跌落，站在地面或岩台顶恢复；西北侧遗物匣按 E 收集风之印记。
- 营地 → 林间路标 → 山脊岔口 → 风塔山脚，蓝色路标与分段发现提示；附近按 E 阅读符文石。
- 程序山地与风塔；Meadow Forest 的树木、岩石、草花、蘑菇、帐篷、符文石和地表贴图。
- Anime Fantasy Pack 2 男剑士作为旅行者，保留原模型、骨骼和身体/衣服/头发贴图。
- WASD / 方向键：相机相对移动；Shift：奔跑；空格：跳跃。
- 按住鼠标右键拖动：旋转镜头；滚轮：改变距离；G：切换星球俯瞰。
- 可沿球面走出起始区域，穿越经度接缝和两极；绕行一周回到原处。外围地形及树石按区块生成，远处降低精度。
- Esc：暂停/继续；Enter：暂停/继续；R：重新出发，重置镜头、本轮探索进度、生命、守卫、石块和完成状态。
- 失焦或最小化暂停并清空按键；恢复后按 Enter/Esc 继续。
- 窗口缩放保持 3:2 内容比例，其余区域留边。

碰撞覆盖岩台顶面/四壁、地形、树干、岩石、帐篷、符文石和外围生成的树石；镜头对地形及这些障碍进行避让，遇障立即收近，离开后平滑恢复距离。
风塔激活需要守卫已被击败且圆盘已充能；隐藏遗物不作为主线通关条件。树冠为装饰，塔身仍为地标几何，没有可进入内部。
星球是有限闭合球面，半径 1000m、周长约 6.28km，并非地球尺度或无限地图；外围目前只有程序地形和树石，没有新增任务、海洋或生态系统。尚未实现复杂任务和存档。推石限制在固定轨道，可前后推拉且不会掉出轨道，没有自由刚体物理。守卫、练习剑为几何原型，守卫没有导航网格、角色间实体碰撞或正式骨骼动作。攀爬仅限指定岩台南侧；滑翔翼、岩台和遗物匣为几何原型，没有坠落伤害。
所选 Fantasy FBX 没有内嵌动作，目前通过真实骨骼程序生成站立、行走、跳跃、攀爬、滑翔、挥剑、闪避和推石姿态，包含起停与冲刺混合、平滑转向、呼吸、躯干扭转、屈肘摆臂、屈膝回收和落地缓冲；尚非正式动画剪辑或布料模拟，也没有脚部地形 IK。
该原型用于验证后续探索玩法的技术基础，已能从营地走到区域完成，仍非正式成品。

## 验证

```bash
bash packages/apps/windward/tests/run-tests.sh
```

测试依赖 Xvfb、Mesa/OpenGL、gcc、X11 开发库与 JDK。
先运行无窗口移动/碰撞/相机测试，再创建真实 GL 场景，最后通过隔离 APK
ClassLoader 打开框架 X11 窗口，检查输入分发、暂停、重开、镜头拖动、失焦、缩放和线程释放。
截图输出到 `out/windward-tests/`，性能数字仅计离屏绘制/读回，不代表端到端屏幕帧率。
可通过 `-Dframework.windward.profile=true` 显示绘制/读回耗时。

## 素材导入

```bash
python3 packages/apps/windward/tools/import-assets.py
bash packages/apps/build.sh windward
```

导入脚本选取 Meadow Forest 的 9 个场景模型、Fantasy 的 1 个完整角色，以及 11 张贴图，
TGA 无损转换为 PNG；仅运行时选用的副本进入 `res/world/`。
`res/world/asset-manifest.json` 记录包名、原始路径、原文件和输出文件的 SHA-256。
运行和构建使用已经导入的副本，无需原包、Unity 或竞技场应用。
`required-apk-entries.txt` 确保资源、Assimp 及原生库正确打包。

纹理加载至 GPU 时最长边限制为 1024 并生成 mipmap；原始分辨率 PNG 保留在 APK。
身体/衣服/头发材质显式映射，不使用 FBX 中已失效的作者本机路径。
场景选择单档 LOD 并缓存静态几何；树叶和花草使用透明裁切。
帐篷、符文石和岩石使用与显示占地对应的保守圆柱碰撞；未实现复杂网格碰撞。
只使用可移植 FBX/贴图，不执行 Unity Prefab、Shader Graph 或 C#。
素材使用遵循各原始资源包授权。

当前提供的 Meadow Forest 原始压缩包未通过 `gzip -t` CRC 校验，因此导入工具读取
`external/extracted/meadow-forest/res/forest/complete/`，逐文件验证其清单 SHA-256。
本次选用的 17 个森林资源与首次从原包提取的源字节校验值全部一致。
Fantasy 原包通过完整性检查，直接从原包顺序读取。两种输入仅在重新导入素材时需要。
