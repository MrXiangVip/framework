# KOF · The King of Fighters

入口：`com.packages.kof.MainActivity`。这是基于本仓库 Java / X11 框架的本地格斗游戏。

## 界面与流程

按照 `res/drawable/design.jpg` 的布局重做：中间纵向排列“单人训练、人机对战、双人对战”，底部横排六个对战背景。点击背景会立即预览，进入战斗后沿用选择；返回主菜单保留场景和模式。

主菜单使用 ↑ / ↓ 或 W / S 选择模式，← / → 或 A / D 切换背景，Enter 进入选角；也可以直接点击模式卡片。选角使用 A / D、方向键、数字 1 / 2，Enter 确认。双人模式依次确认 1P 和 2P，可选择相同角色。

- **单人训练**：场上仅玩家所选的一名人物，不计时，无对手、碰撞阻挡或胜负结算。可自由移动、跳跃、下蹲和四种轻重攻击，能量自动补满；移动方向决定人物朝向。R 重置练习。
- **人机对战**：电脑自动控制对手，一局 60 秒，KO 或时间结束判定胜负。
- **双人对战**：本机双人，独立选角、移动、跳跃、下蹲、攻击，无 AI。一局 60 秒。

| 操作 | 1P | 2P（双人模式） |
| --- | --- | --- |
| 移动 | A / D | ← / → |
| 跳跃 | W / 空格 | ↑ |
| 下蹲 | 按住 S | 按住 ↓ |
| 轻拳 | J | 1 |
| 轻脚 | K | 2 |
| 重拳 | L | 3 |
| 重脚 | ;（英文分号键） | 4 |
| 站防 | 按住背离敌人的方向 A / D | 按住背离敌人的方向 ← / → |
| 蹲防 | 后方向 + S | 后方向 + ↓ |

J、K、L、; 分别独立触发轻拳、轻脚、重拳、重脚，无需组合键。防御采用相对敌人的后方向：敌人在右侧时 A 站防、A+S 蹲防；敌人在左侧时 D 站防、D+S 蹲防。换边后自动切换后方向，双人模式 2P 的方向键遵循同一规则。训练模式无敌人，不启用方向防御。防御时停止移动，松开后解除；空中、出招和受击硬直期间不能防御。防御沿用现有减伤规则，站防与蹲防不额外区分攻击类型。按住后方向时也可按攻击键转为出招。轻攻击出招、收招较快，伤害和攻击距离较低；重攻击伤害及攻击距离更高，收招较慢。按住 S 下蹲，松开站起；下蹲时停止移动且不能起跳，但可以出招。攻击需松开后再次按下，键盘自动重复不会连续出招。

2P 的数字操作同时支持主键盘和开启 Num Lock 的数字小键盘。单人模式也支持方向键移动、跳跃。P 暂停 / 继续，Esc 返回主菜单，M 切换音效。屏幕按钮用于 1P 鼠标操作；双人推荐键盘，受键盘硬件同时按键数量限制。失去焦点会暂停并释放双方控制。

结算显示胜负，3.5 秒后自动返回主菜单，Enter 可提前返回。窗口缩放时保持 16:9，点击位置随内容缩放；竖屏采用留黑边方式。

## 场景与资源

`StageArt` 用 Java2D 绘制霓虹天台、落日港湾、月下道场、钢铁工厂、雪山之巅、午夜机场；缩略图、菜单预览与实际战场共用场景。角色池只保留孙悟空、猪八戒，两者均使用各自八组动作精灵图；旧矢量人物及其渲染分支已移除。运行不依赖旧的 `choice.jpeg` / `battle.jpeg`。设计图仅为布局参考，不作为游戏背景。

`res/fonts/NotoSansCJKsc-Regular.otf` 及 `OFL-CJK.txt` 来自仓库现有字体，独立打包保证 Linux 中文显示。声音沿用合成音效；没有音频设备时仍可游戏，`-Dframework.kof.sound=false` 默认静音。

## 构建与验证

仓库根目录执行：

```sh
bash packages/apps/build.sh kof
bash packages/apps/kof/tests/run-tests.sh
```

产物为 `out/system/app/kof/kof.apk`。测试编译当前框架及 KOF 源码，无需 X11，覆盖两位角色的三种模式、真实精灵资源与八种动作、双人同角色动画独立性、四种轻重攻击、方向防御、暂停和不计时训练，并输出截图至 `out/kof-tests/previews`。实际窗口运行需要仓库的 Linux / X11 环境。

## 孙悟空与猪八戒

单人训练、人机对战和双人对战均可选择孙悟空、猪八戒。数字 1 选择孙悟空、2 选择猪八戒，也可点击卡片或使用方向键。人机模式自动选择另一位英雄作为电脑对手；双人模式依次确认 1P、2P，允许同角色对战。主菜单、选角预览、头像和战场均使用精灵图片。

`FighterSprites` 从 APK 的 `res/drawable/sunwukong`、`res/drawable/zhubajie` 加载动作。孙悟空保留原有六张八帧、两张六帧素材及对应切分；猪八戒的八张 PNG 均为 4352×544、六帧横向动作，按每张图实际姿势边界切分。加载时清理烘焙棋盘背景、地面线和相邻帧碎片，不修改提供的原图。

待机、行走循环播放；孙悟空下蹲保持末帧，猪八戒下蹲图末尾是站起，因此按住 S 时保持第五帧；松开后恢复待机。跳跃和四种攻击分别跟随角色状态与出招时间，左右方向镜像，脚底对齐。两名战斗人物共享图片资源，各自持有播放状态，同角色也不会串帧；暂停冻结双方动画。

当前八组素材不含专门的防御、受击、倒地、胜负及必杀动画。防御复用站立/下蹲基础姿势并显示护盾弧线，受击叠加命中特效，KO 旋转基础姿势；双方及电脑仅使用已有四种轻重攻击，不启用 U / 必杀。训练始终只有玩家一位人物，不计时，R 重置练习。

已有素材与建议补充动作见 [精灵素材清单](SPRITES.md)。
