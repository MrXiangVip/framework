# 星隙竞技场 / Rift Arena

基于本仓库 Java 8 / Linux X11 系统的原创低多边形 3D 单路 MOBA。由 Launcher 直接进入框架窗口中的游戏，不需要 Unity、外部游戏进程或网络下载。应用名仍为“星隙竞技场”。

## 构建与启动

在仓库根目录执行：

```bash
bash packages/apps/build.sh rift-arena
# 启动系统，点击桌面“星隙竞技场”（可能在后续桌面页）
bash build.sh
```

产物：`out/system/app/rift-arena/rift-arena.apk`，包含游戏 Java 类、LWJGL 与 Linux x86_64 本地库。这是自研桌面 JVM 框架的应用包，不是标准 Android 手机 APK。

需要 Java 8+、Linux x86_64、X11 DISPLAY、OpenGL 2.1 和 framebuffer object 支持。依赖已随应用提供。当前使用隐藏 OpenGL 上下文，在工作线程中渲染离屏 framebuffer，再由框架 Canvas 显示；没有可见的外部游戏窗口。窗口默认 1200×800，缩放保持 3:2 比例。离屏分辨率 900×600，对战目标约 60 FPS，菜单/暂停约 10 FPS，实际性能取决于驱动和像素读回开销。

## 可玩内容

- 选角：破晓剑士（近战高血量）、逐星游侠（远程）、苍穹法师（中程）；三者的生命、攻击、射程与造型不同，沿用 Q/E/R 三个键位，剑士及游侠 Q/E 已有独立行为。
- 单路地图、河道、桥梁、双方泉水、防御塔和水晶；装饰场景不参与碰撞，角色移动限制在地图边界。
- 一名玩家对抗一名电脑英雄，双方自动出兵；首波 3 秒出现，之后每 14 秒各出 4 名士兵。
- 防御塔优先攻击范围内小兵；塔存活时同阵营水晶免疫伤害。先拆塔，再摧毁敌方水晶获胜。
- 近身友军击杀奖励金币与经验，升级提升生命和攻击；泉水恢复生命并支持购买两种可叠加的装备升级。
- 三种技能、瞄准标记、普攻光束、血条、小地图、回城引导、阵亡复活、暂停、胜负结算与重开。
- 关闭窗口释放渲染线程和 OpenGL 资源，失去焦点或 Activity 暂停会暂停对战并清空按键。

## 代码

- `MainActivity.java`：窗口和生命周期。
- `ArenaView.java`：选角、操作、HUD、线程消息与不可变画面快照。
- `ArenaWorld.java`：独立于图形的战斗模拟，最长 25ms 子步进。
- `ArenaAssets.java`：从 APK 读取 FBX，通过 Assimp 加载网格、法线、UV 和树叶遮罩。
- `ArenaRenderer.java`：俯视跟随镜头、3D 地图、角色和技能表现；静态场景缓存为 OpenGL display list。
- `libs/` 与 `res/third-party/`：本地依赖、校验值和许可证。

## 森林模型替换

模型和贴图以独立副本放在 `res/arena/`，可独立构建和运行。`asset-manifest.json` 记录原始资源路径及 SHA-256；运行时选择 17 个模型和 14 张纹理（其中一张叶片变体保留备用），没有将完整 697 MiB 森林资源包塞入游戏。资源来自用户本地的 Synty Meadow Forest 包，使用遵循原资源包授权。

- 英雄与小兵：使用 Toon RTS Dwarves 的重步兵（剑士）、弓箭手（游侠）、牧师（法师）和轻步兵（小兵）四种独立模型，自带装备。蓝红阵营使用原包的蓝色和红色贴图，并保留脚底标记。旧稻草人与独立剑模型已移除。
- 地图装饰：树、白桦、两类岩石、草、花、蘑菇、小屋和石中剑；加入少量蝴蝶装饰。
- 人物和植物使用原色板、UV 与透明贴图；树叶按源模型顶点颜色拆分；选择一档 LOD。
- 四种人物已接入真实骨骼待机、跑步、普攻、受击和死亡动作，使用同套矮人骨骼；施法暂时仍使用现有效果。
- 静态模型和地图装饰缓存为 OpenGL display list；角色单独保留骨骼、权重和动作数据，以 CPU 蒙皮和复用的顶点缓冲绘制。关闭时释放图形资源。装饰不参与碰撞。

## 人物素材库

仓库根目录 `external/extracted/characters/` 保存从用户本地 Unity 包提取的可移植 FBX 模型、动作和纹理；仅运行时选用的模型、动作和纹理随 APK 打包：

- `dwarves/`：矮人兵种、武器、配色和动作。
- `manifest.json`：每项文件的来源包、原路径、输出路径和 SHA-256；也记录运行时选用的四个模型及两张转换贴图。

重新导入：`python3 packages/apps/rift-arena/tools/import-characters.py`。只依赖 Python 标准库；源包位于仓库根目录 `external/unity/dwarves/`。Unity 场景、Prefab、C# 和 Magica Cloth 插件不导入。素材使用遵循各原包授权。

## 地面与河道资源

使用 `python3 packages/apps/rift-arena/tools/import-landscape.py` 从本地
`external/extracted/meadow-forest/res/forest/complete/` 提取地形和建筑原始资源：草地、泥土、步道石板、碎石贴图，以及木桥、岩壁和岩石堆 FBX。输出为独立资源，运行时不依赖 Meadow Forest；来源和 SHA-256 写入 `asset-manifest.json`，打包必需项同步写入 `required-apk-entries.txt`。

地图使用连续草地和重复石板 UV，路肩以不规则泥土和透明边缘过渡；河床下沉，加入碎石岸坡、岩壁与浅深水色过渡，原几何桥替换为木桥。树木和岩石调整组合，人物和部分场景物件使用渐隐的接触阴影。纹理生成 mipmap 以减少远处纹理与树叶的闪烁。当前水面仍是静态色带，接触阴影不是实时投射阴影；未接入法线贴图或 Unity Shader Graph。场景装饰和桥仍不参与碰撞。

普攻点按请求进入模拟线程队列，快速按下后立即松开也可触发；连按和长按遵守 0.72 秒攻击间隔。无目标攻击仅展示特效，不对远处敌人造成伤害。剑士使用沿武器骨骼轨迹的斩击，远程使用移动光迹，并播放配套骨骼攻击动作。图形测试额外输出 `basic-attack.png`。

普攻表现增强：近战以半透明宽幅刀光和高亮刃缘表现，远程以发光弹道和亮核表现；使用配套骨骼攻击动作和命中短暂高亮，实际伤害触发火花与上浮伤害数字。剑士动作持续 0.66 秒，其他普攻表现持续 0.46 秒；伤害数字持续 0.65 秒，攻击间隔仍为 0.72 秒。图形测试输出 `attack-impact.png`。

移动输入优化：WASD/方向键按下和松开会立即唤醒渲染线程，对战帧间隔目标为 16.7ms；实际帧率受驱动、读回和框架显示开销影响。像素读回改为原生打包颜色逐行批量复制，UI 合成缓冲在窗口尺寸不变时复用，以减少逐像素转换及分配开销。

## 原创背景音乐

`res/arena/audio/menu.wav`（选角、结算）和 `battle.wav`（对战）为本项目原创程序合成器乐，不含外部录音采样；每段约 34.3 秒，112 BPM，16 小节，22050 Hz / 16-bit / 立体声，无缝循环。菜单使用轻柔铺底与钟琴式琶音，对战增加旋律、低音与合成打击乐。生成脚本：`python3 packages/apps/rift-arena/tools/generate-music.py`；音频清单记录 SHA-256。

进入游戏自动播放，暂停或失去焦点停止输出，继续后恢复。按 M 或点击右上角声音按钮静音/恢复，关闭窗口释放音频设备。音频加载、设备打开和播放在独立线程执行，未检测到设备时显示“声音不可用”，不影响对战。剑士普攻已加入原创挥砍和命中音效，剑士震荡斩已加入蓄力和落击音效，其他技能音效尚未接入；已增加建筑撞击与击杀提示音。

攻击表现不再叠加整体模型的左右旋转，收招保持攻击目标方向；移动时仍根据移动方向转身。

右键追击目标失效后清除旧移动目的地；空格普攻取消旧追击/地面移动指令。长按空格在目标消失后沿用上次攻击朝向，主动点按空格空挥才朝鼠标瞄准，WASD 仍可随时移动转向。

每次攻击将出手方向保存为独立的 attackFacing，角色攻击姿态与弹道/刀光共用表现时间（剑士 0.66 秒，其他 0.46 秒）；期间移动位置照常更新，角色保持朝攻击方向，结束后恢复当前移动朝向。姿态计时与攻击冷却分离。

## 骨骼动画

`ArenaRig.java` 采用独立 FBX 导入流程，保留 Assimp 的骨骼层级与 FBX pivot 节点，复制网格、法线、UV、骨骼偏移矩阵、全部顶点权重及动画关键帧。位置/缩放线性插值，旋转采用最短路径四元数 slerp。每帧按层级求全局姿态，以全局骨骼矩阵乘偏移矩阵蒙皮；法线使用逆转置，绑定姿态与旧静态几何的坐标通过容差测试校验。

`ArenaAnimator.java` 为每个角色维护播放状态、按状态约 25～65ms 的姿态混合和复用的 CPU 蒙皮缓冲，当前四种角色均接入待机、跑步、攻击、受击、死亡。跑步依据移动距离推进，攻击与现有特效共用表现时间（剑士 0.66 秒，其他 0.46 秒），移除旧整体起伏/俯身模拟。死亡优先于攻击，攻击优先于独立受击动作（攻击中仍有短暂停顿和视觉回弹）；英雄尸体保持最终死亡姿态直至复活，小兵尸体保留两秒再清理，不再参与战斗。

`python3 packages/apps/rift-arena/tools/import-animations.py` 从现有矮人素材库提取 19 个 FBX（步兵九个，含冲锋、第二段攻击、战斗待机与战斗行走；弓箭手/法师各五个，小兵复用基础步兵动作），约 4.6 MiB，输出到 `res/arena/animations/`，附来源路径和 SHA-256 清单。重新导入角色库不影响这些运行时副本。

当前采用 CPU 蒙皮，未引入 GPU 骨骼着色器；大量单位下的性能仍需要真实桌面测量。剑士普攻使用动画命中事件，游侠普攻在放箭后由飞行弹体结算，其余攻击沿用即时结算；剑士震荡斩已接入重新定时的重劈动作，Q 已接入独立冲锋动作，R 已接入重新定时的举剑蓄力与收招动作。测试覆盖全部角色的绑定姿态、权重、法线、UV、五种动作变形及状态切换，真实 OpenGL 动作对照图为 `out/rift-arena-tests/skeletal-animation.png`。

## 剑士普攻优化

使用现有步兵举起武器向前劈下的真实骨骼动作，单次动作 0.66 秒，在 30% 进度（约 0.20 秒）统一触发伤害、受击高亮、火花、伤害数字和命中音效；挥砍音效在 22% 进度开始。刀光由右手所持武器的真实蒙皮顶点轨迹生成，随人物朝向和缩放绘制，仅在挥砍段出现。现有角色原模型持斧盾，未替换装备模型。

起手阶段移动或施法会取消待结算普攻，保留原攻击冷却；命中时再次校验目标存活、距离和前方扇区，防止目标跑远或绕到背后仍扣血。空挥只有挥砍音效，不产生伤害或命中音效；暂停冻结命中事件，重开清空事件。

`python3 packages/apps/rift-arena/tools/generate-sword-audio.py` 生成原创短音效 `sword-swing.wav`、`sword-hit.wav`，不含外部录音；音频线程混合背景音乐与音效，使用 16-bit 饱和处理及有界队列，按 M 同时静音音乐和音效。新增模拟回归覆盖命中时机、取消、死亡、脱离范围、背后目标、暂停和空挥；实际 OpenGL 连续截图为 `out/rift-arena-tests/sword-attack.png`。

## 受击反馈

命中剑士普攻时，攻击者动作停顿 30ms，人物目标动作停顿 35ms；只暂停表现动作计时，不冻结输入、移动、技能冷却或整场游戏。受击动画独立持续 260ms，高亮缩短为 120ms，进入受击姿态的混合缩短为 35ms；重复命中重新触发短反应，不累计额外停顿时长。身体沿来袭方向产生最多 0.18 单位视觉回弹，不修改碰撞位置、朝向或攻击目标。死亡立即退出受击停顿，继续原骨骼死亡动作。

普通攻击火花集中到目标靠近来袭者的一侧，按英雄、小兵和建筑调整高度，并增加快速衰减的定向碎光。建筑不播放人物受击动作，剑士命中建筑使用原创石质撞击音效；附近友方击杀播放短提示音。新音效仍由 `generate-sword-audio.py` 合成，遵循 M 静音和暂停控制。技能命中特效暂沿用中心位置。

验证包括局部停顿、移动响应、朝向/物理位置不变、反馈恢复、重复命中、死亡优先级、建筑分支和真实骨骼停帧；OpenGL 连续截图为 `out/rift-arena-tests/hit-feedback.png`。

## 剑士 E 震荡斩

沿用现有快捷键 **E**（W 仍为前移），复用同骨骼步兵 `07_attack_A` 举起武器、向前劈下和收招动作，无需新增模型或动画资源。`ArenaAnimator` 新增独立震荡斩状态，将源动作非线性重新定时：0～0.23 秒举起，0.23～0.32 秒快速下劈，随后收招；动作总计 0.74 秒，落击仍对应已校准的源动作 30% 进度，刀光使用同一武器蒙皮轨迹。

蓄力显示六单位范围圈与渐亮圆环，落击才结算六单位内敌人的范围伤害（135 + 等级 × 15），同时生成扩散冲击波、短碎光、定向受击反馈及原创低沉撞击音效；落击带 40ms 局部动作停顿。冷却仍为九秒，友军、已死亡目标和有护盾的水晶不受伤害，范围在落击时重新检查。

施放会替换当前普攻并清除旧追击/地面移动指令，蓄力中普攻不会盖掉动作；移动、其他技能、回城或死亡会取消未完成的重劈，不产生延迟伤害，取消保留冷却。落击后移动可提前退出收招。暂停冻结动作与命中时刻，重开清空状态。音频线程支持停止已取消的蓄力音效，按 M 和暂停规则统一控制；界面 E 按钮显示“蓄力 / 收招”。其他英雄技能行为保持原样，Q 冲锋动作已接入，R 举剑施法与星陨反馈也已接入。

## 操作响应调整

移动立即退出玩家的普攻收招、受击停顿和受击姿态，人物朝向立即跟随新移动输入，旧刀光同时清理；已结算伤害不撤回。跑步/普攻切换混合缩短为 30ms，震荡斩切入为 40ms，受击切入为 25ms，其他切换为 65ms。键盘与鼠标移动、按钮操作都会立即唤醒渲染线程。

普攻增加 140ms 的短输入缓冲：冷却即将结束时点按空格可在冷却结束后自动出手，超过缓冲期的旧输入丢弃；移动、暂停、技能、死亡和重开会清理旧缓冲，避免意外攻击。新按下的攻击仍可在移动中触发。普攻原攻击间隔不变，震荡斩仍为九秒冷却。

`ArenaResponseTest` 验证移动首个模拟步响应、收招/受击打断、攻击缓冲和清理；OpenGL 测试额外报告 34 个角色下的渲染加像素读回耗时（不包含原生窗口输入/呈现，因此不能当作端到端输入延迟）。

持续按住的移动输入不再每帧取消新攻击；跑动中施放震荡斩会站定完成蓄力，新的移动方向或松开后重新移动仍可取消。新增回归覆盖边走边普攻和行走中施放技能。

## 静态地图缓存与屏幕外裁剪

性能分段测量确认，主要开销来自每帧重新绘制静态地图，角色蒙皮和像素读回占比较小。地图现在以原有像素密度一次绘制到覆盖全部合法镜头位置的颜色/深度缓冲，后续通过 framebuffer blit 复制可见区域，再绘制角色与特效。900×600 输出不变，材质、模型和角色动画频率不降低；缓存约增加 8 MiB 显存/缓冲内存，首次建立缓存计入加载成本。

镜头按一个渲染像素对齐滚动，动态几何使用同一镜头；视图深度与镜头平移解耦，使复制的深度仍能正确遮挡人物、火花和地面效果。此缓存适用于目前固定地图；以后加入可破坏树木或动态地形时，需要将变化物件移出静态层或重新建立缓存。

保守视口边界覆盖人物动作、武器伸展与阴影，屏幕外单位跳过绘制及骨骼更新，屏幕内人物保持原更新频率。离屏影响特效和蝴蝶也跳过绘制；战斗模拟、出兵、寻路、伤害及 HUD/小地图数据照常更新。

同次 Xvfb/Mesa llvmpipe 测试，900×600，预热后取 40 帧中位数：

| 场景 | 关闭地图缓存 | 开启地图缓存 |
| --- | ---: | ---: |
| 2 个角色 | 31.28ms | 2.02ms |
| 34 个角色 | 34.10ms | 5.59ms |

以上是 OpenGL 绘制与像素读回耗时，不包含框架界面合成、原生窗口呈现或端到端输入延迟，不能直接当作实际游戏帧率。分段诊断模式才会调用额外 glFinish；正常渲染不增加这些同步。

复现性能对照：`bash packages/apps/rift-arena/tests/run-tests.sh --performance`。`ArenaSceneCacheTest` 对七组镜头、视野边界、树木遮挡、动态人物与技能效果做缓存开关像素对照，另验证离屏模拟继续运行及裁剪不会改变可见像素。对照图：`out/rift-arena-tests/scene-cache-parity.png`；测量记录：`out/rift-arena-tests/render-performance.txt`。

`bow-release.wav` 与 `arrow-hit.wav` 为现有音效脚本生成的原创合成音效，建筑使用石质撞击声，均遵循静音、暂停和设备释放规则。`ArenaArrowTest` 覆盖拉弓/放箭/抵达、单次及固定伤害、连续位移、取消、射程、目标死亡、射手死亡、暂停、空射、水晶护盾和建筑分支；真实 OpenGL 连续截图为 `out/rift-arena-tests/archer-attack.png`。


## 游侠 Q 后撤射击

游侠 Q 改为保持施放时的瞄准朝向，在 0.24 秒内沿反方向连续后撤四单位，以减速曲线停下；不再对后撤路径造成伤害。动作使用矮人包弓箭手 `06_combat_walk` 反向采样，配合轻微后倾及短青色残影，并非新增专用后跳动画。该动作作为第二十个运行时动画导入，来源与 SHA-256 保存在动画清单。

后撤结束后进入原有 0.18 秒拉弓，向起手时保存方向射出强化箭。射击从后撤终点沿该方向查找十四单位内、中心线左右 1.6 单位范围的最近有效敌人，随后沿用普攻的追踪箭矢；没有目标则向前空射，不产生伤害。强化箭在抵达时结算起手保存的 `110 + 等级×12`，单次伤害，遵守友军、死亡与水晶护盾过滤。Q 冷却仍为六秒，射击重置至少 0.72 秒普攻间隔，避免立即叠加一发普攻。

持续按住移动输入会等待后撤和拉弓完成，放箭后恢复移动；后撤途中按住或末段点按空格保留原输入缓冲规则。拉弓时新移动方向可取消射击，E/R、回城或死亡可终止未完成的后撤/射击，保留技能冷却。放出的箭独立飞行，暂停冻结，重开清空；位移限制在地图边界，不提供无敌。技能栏使用后撤箭头和“后撤射击”名称，显示“后撤 / 拉弓”状态，沿用位移风声、放箭与命中音效。

`ArenaRetreatTest` 验证连续反向位移、固定朝向、延迟强化箭、一次伤害、取消、持续移动恢复、冷却、暂停、死亡、边界与重开；骨骼测试增加第六个弓箭手动作及后撤到攻击的切换验证。实际 OpenGL 连续截图为 `out/rift-arena-tests/archer-retreat.png`。


## 游侠 E 扇形散射

游侠 E 使用原有弓箭手拉弓动作，0.18 秒后沿起手瞄准方向与两侧各 18 度释放三支箭。箭以 28 单位/秒直线飞行十二单位，不追踪目标。每帧用线段与单位圆形范围的交点检测最先接触的敌人，避免低帧率穿透；每支箭遇到第一个敌人后消失，三个弹体共享本次施法命中集合，同一敌人最多受到一次 `135 + 等级×15` 伤害，伤害在起手时保存。友军不阻挡；护盾水晶不受伤但会阻挡，已被本次其他箭命中的敌人同样会消耗后续箭。树木、岩石及桥栏继续沿用无碰撞装饰规则。

E 可用时显示淡色三路瞄准线与扇形边界，拉弓时高亮并固定起手方向，图标改为三箭，“扇形散射”名称与“拉弓”状态同步。新增原创合成 `scatter-release.wav`，命中人物沿用箭矢音效，建筑使用石质音效，遵循静音和暂停。技能冷却九秒，普攻间隔至少保留 0.72 秒。

新移动方向、Q/R、回城或死亡取消未完成的拉弓并保留冷却；持续移动在出箭后恢复，已释放的三箭不受射手后续动作或死亡影响，暂停冻结，达到射程/地图边界清除，重开清空。Q 后撤中接 E 会中断后撤及未放出的强化箭，改为散射；已放出的 Q 箭独立飞行。

`ArenaScatterTest` 覆盖延迟释放、三路目标、连续飞行、最先接触阻挡、近身及宽体目标不重复受伤、友军、水晶护盾、取消、Q 衔接、持续移动、暂停、死亡、射程和重开。真实 OpenGL 动作序列为 `archer-scatter.png`，实际界面图为 `scatter-aim-ui.png`、`scatter-charge-ui.png` 和 `scatter-flight-ui.png`，位于 `out/rift-arena-tests/`。

## WASD 操控响应

玩家持续按住方向键时，剑士普攻命中后即可退出收招，E 落地后即可恢复移动；起手仍保留，避免持续走路使攻击永远无法命中。新方向输入仍可取消普攻或技能起手。玩家走路立即转向，受击闪光继续显示，但不再抢占走路动画。松键停止位移，斜向移动保持与单轴相同速度。相关逻辑与动画回归由 ArenaResponseTest 和 ArenaRigTest 覆盖。
