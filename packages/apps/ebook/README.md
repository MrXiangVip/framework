# 电子书

基于本仓库 Java / X11 框架的本地电子书应用。参考同目录 `20261106-145625.jpg`，使用白底三列封面、书架层板和红色导航。11 张封面由参考图裁切，保留原图；内置正文为原创演示文字，与封面小说无关。书城为本地展示，免费专区为示例筛选，不提供在线下载或付费服务。

## 使用

- 点击封面进入阅读；书架支持滚轮、上下拖动浏览。
- 点击右上角“导入”，浏览目录并选择 `.txt` / `.epub` / `.md` / `.markdown` / `.pdf`；也可直接输入完整路径，按 Enter 或“打开路径”。Ctrl+U 清空路径，Esc 取消。
- 导入成功后自动进入阅读；书架支持搜索导入书籍。重复导入同一文件会打开已有书籍，不会清除进度。
- 点击搜索后直接输入书名，支持中文输入、退格清除、Esc 退出。
- 阅读时点击上一页/下一页，或使用左右方向键；Esc 返回书架。
- A− / A+ 调整字号，日间/夜间切换主题；书签按钮保存当前位置，“转到书签”恢复。
- “我的”显示已读数量，并可继续上次阅读。
- 进度、书签、字号、主题保存在 `~/.local/share/framework/ebook/reading.properties`。
- 导入后的正文副本和书名保存在 `~/.local/share/framework/ebook/books/`，之后移动或删除源文件仍可阅读。导入在后台线程执行，结果回到应用 UI 线程处理。

## 构建与验证

仓库根目录运行：

```sh
bash packages/apps/ebook/build.sh
bash packages/apps/ebook/tests/run-tests.sh
```

产物：`out/system/app/ebook/ebook.apk`。根目录 `bash build.sh` 自动发现并打包本应用，重启框架后桌面显示“电子书”。这是桌面 JVM 包，不是标准 Android APK。

无窗口测试使用临时用户目录，覆盖封面、阅读、窗口尺寸，以及 UTF-8 BOM、中文与表情、换行归一化、EPUB 2/3 章节顺序、相对路径与 URI 编码、HTML 实体、元数据与正文提取、损坏文件、大小限制、异步文件选择流程、导入失败与取消、重复导入、搜索、书签、源文件删除和重启恢复，以及 Markdown 异步导入、标题/行内样式、列表/引用/代码/表格、本地插图复制与恢复、缺失/SVG 占位；预览输出到 `out/ebook-tests`。尚未验证真实 X11 窗口中的输入法操作。

## 支持范围

- **TXT**：严格按 UTF-8 解码，支持带/不带 BOM，兼容 LF / CRLF / CR 换行；不支持 GBK 等编码，遇到无效编码显示转换提示。
- **Markdown**：支持 UTF-8 `.md` / `.markdown`，从第一个标题提取书名（无标题时使用文件名）；渲染 ATX / Setext 标题、粗体、斜体、行内代码、有序/无序列表、引用、围栏代码块、分隔线及简单管道表格。物理换行保留，不支持完整 CommonMark / GFM 规范。
- Markdown 支持 `![说明](images/picture.png)` 形式的本地 PNG / JPEG / GIF 插图，支持相对路径与 URI 编码；图片必须位于 MD 所在目录或其子目录，导入时保存独立副本，GIF 只显示静态首帧。重复导入相同 MD 保留已有插图副本。
- Markdown 中的 SVG、远程图片、缺失/过大/无法解码的图片显示说明占位；不执行 HTML、不加载远程资源。链接仅显示文字，暂不能点击跳转；暂不支持数学公式、脚注、引用式图片、语法高亮、跨 MD 文件合并或原课本固定分页。宽表格会折行，不保留复杂表格版式。
- Markdown 插图单张最大 8 MB，累计最大 32 MB，图片引用最多 256 个，超大尺寸/解码预算不足时使用占位。书籍根据当前窗口和字号重新分页。
- **EPUB**：支持常见 EPUB 2 / EPUB 3 的 HTML/XHTML 文字章节，读取 OPF 书名，按 spine 指定的顺序拼接正文；保留段落、标题与换行，去除标记、脚本和样式。
- EPUB 当前以纯文字重新分页，不显示原书图片/封面、不保留 CSS 或固定版式，也没有章节目录导航；带 `META-INF/encryption.xml` 的书籍暂不支持（包括部分仅字体加密的 EPUB）。
- 导入书籍使用自动生成的文字封面。书城和免费专区仍是内置示例展示。
- TXT / EPUB / Markdown 源文件最大 32 MB，归一化正文最大 8 MB，EPUB 单个读取资源最大 8 MB、累计解压读取最大 32 MB；空书、缺失章节、非法路径和超限文件会提示导入失败。
- 当前不支持 MOBI / AZW，也没有联网书源。
- 进度和书签按当前分页页码保存；调整窗口或字号后页码布局会变化。

## Markdown 示例

可直接导入 `packages/apps/ebook/examples/课本示例.md`，配套插图位于 `examples/images/shapes.png`，演示文字与插图混合分页。预览见 `out/ebook-tests/markdown-reader.png`。

每次导入一个 MD 文件作为一本书；若按页编写了多个 MD 文件，目前需分别导入或先合并为一个 MD。

## PDF 阅读

支持导入不加密的 `.pdf`（含扫描图片教材），最大 256 MB。保存完整 PDF 副本，删除或移动源文件后仍可阅读；同一文件重复导入不会新增书籍或清除进度。

使用 Apache PDFBox 3.0.7 按原始页面渲染，保留插图、公式和固定排版。默认整页适应窗口；顶部“缩− / 缩+”在 1～4 倍间缩放，放大后按住鼠标左键拖动页面。左右键、滚轮及底部按钮翻页，支持原始页码进度和书签保存。窗口缩放不会改变教材页码。夜间模式仅改变周围界面，PDF 页面保留原色。

PDF 页面在后台按需渲染，仅保留当前页面图像，单页输出限制为 800 万像素。暂不提供 PDF 文字选择、全文搜索、目录导航、链接跳转、表单或密码输入；不会自动给扫描教材做 OCR。复杂文档和缺失字体的页面可能无法完全还原。真实 X11 窗口的拖动操作尚需人工验证。

依赖和授权见 [libs/README.md](libs/README.md)。测试覆盖 PDF 原始颜色、逐页显示、重复导入、损坏/加密/超限拒绝、源文件删除后阅读、后台渲染、翻页、缩放及重启进度恢复；目录中存在提供的教材 PDF 时也渲染其首页，输出 `out/ebook-tests/pdf-textbook.png`。
